# Solana Wallet Tracker Telegram Bot

## Описание проекта

Этот Telegram-бот предназначен для отслеживания транзакций на кошельках Solana. Пользователи могут добавлять и удалять адреса кошельков Solana, просматривать список отслеживаемых кошельков и получать уведомления о новых транзакциях.

Бот использует библиотеку `node-telegram-bot-api` для взаимодействия с Telegram API, `@solana/web3.js` для взаимодействия с блокчейном Solana и `sqlite3` для хранения данных о кошельках пользователей.

## Функционал

*   **Добавление кошельков**: Пользователи могут добавлять адреса кошельков Solana для отслеживания.
*   **Удаление кошельков**: Пользователи могут удалять кошельки из списка отслеживания.
*   **Просмотр списка кошельков**: Команда `/mywallets` показывает все отслеживаемые кошельки.
*   **Уведомления о транзакциях**: Бот периодически проверяет наличие новых транзакций по отслеживаемым кошелькам и отправляет уведомления пользователям, подписанным на данный кошелек. Уведомления включают базовую информацию о транзакции, такую как изменение баланса SOL, статус и ссылку на Solscan.
*   **Валидация адресов**: Проверка корректности адресов Solana перед добавлением.
*   **Локализация**: Сообщения для пользователя на русском языке.
*   **Конфигурация**: Возможность настройки RPC-узла Solana через переменную окружения.

## Настройка и запуск

### 1. Клонирование репозитория

```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd <НАЗВАНИЕ_ДИРЕКТОРИИ_ПРОЕКТА>
```

### 2. Установка зависимостей

Убедитесь, что у вас установлен Node.js (рекомендуется версия 18.x или выше) и npm.

```bash
npm install
```

### 3. Настройка переменных окружения

Создайте файл `.env` в корневой директории проекта. Скопируйте содержимое из `.env.example` (если он есть) или создайте файл вручную и добавьте в него следующие переменные:

```env
TELEGRAM_BOT_TOKEN=ВАШ_ТЕЛЕГРАМ_БОТ_ТОКЕН
SOLANA_RPC_ENDPOINT=АДРЕС_ВАШЕГО_SOLANA_RPC_УЗЛА
```

*   `TELEGRAM_BOT_TOKEN`: Токен вашего Telegram-бота. Его можно получить у [@BotFather](https://t.me/BotFather) в Telegram.
*   `SOLANA_RPC_ENDPOINT`: URL-адрес RPC-узла Solana. По умолчанию, если переменная не установлена, будет использоваться `https://api.mainnet-beta.solana.com`. Вы можете использовать общедоступные узлы (например, от Triton, Helius, QuickNode) или свой собственный.

Пример `.env` файла:
```env
TELEGRAM_BOT_TOKEN=1234567890:ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghi
SOLANA_RPC_ENDPOINT=https://api.mainnet-beta.solana.com
```
**Важно:** Добавьте `.env` в ваш `.gitignore` файл, чтобы случайно не загрузить его в репозиторий.

### 4. Запуск бота

```bash
node src/bot.js
```

После запуска бот начнет работу и будет готов принимать команды в Telegram. Логи работы будут выводиться в консоль.

## Доступные команды

*   `/start` - Показать приветственное сообщение и основные кнопки управления (Добавить/Удалить кошелек).
*   `/mywallets` - Показать список всех отслеживаемых вами кошельков Solana.

### Взаимодействие через кнопки:

*   **➕ Добавить кошелек**: После нажатия бот запросит адрес кошелька Solana. Отправьте адрес в ответном сообщении. Бот проверит его валидность.
*   **➖ Удалить кошелек**: После нажатия бот покажет список ваших кошельков с кнопками для удаления каждого. Также будет доступна кнопка "Отмена".

## Структура проекта

*   `src/`
    *   `bot.js`: Основная логика Telegram-бота, обработка команд, колбэков и сообщений. Инициализация сервиса мониторинга.
    *   `db/database.js`: Управление базой данных SQLite (инициализация, схема, функции для добавления/удаления/получения данных о кошельках и пользователях).
    *   `monitor.js`: Логика мониторинга транзакций на блокчейне Solana. Получает данные о кошельках из БД, опрашивает RPC-узел, форматирует и отправляет уведомления.
*   `package.json`: Список зависимостей и скриптов проекта.
*   `.gitignore`: Файл для исключения ненужных файлов и директорий из Git (например, `node_modules/`, `.env`, `bot_data.db`).
*   `README.md`: Этот файл.
*   `bot_data.db` (создается локально): Файл базы данных SQLite. **Рекомендуется добавить в `.gitignore`, если не планируется его версионирование.**

## Зависимости

*   `node-telegram-bot-api`: для взаимодействия с Telegram API.
*   `@solana/web3.js`: для взаимодействия с блокчейном Solana (валидация адресов, получение транзакций).
*   `sqlite3`: для локального хранения данных (списки кошельков пользователей).

## Логирование

Бот использует `console.log`, `console.warn` и `console.error` для вывода информации о своей работе. Логи содержат префиксы для идентификации модуля:
*   `[DB]` - операции с базой данных.
*   `[Bot]` - логика работы Telegram-бота.
*   `[Monitor]` - логика сервиса мониторинга транзакций.

Это помогает отслеживать состояние и диагностировать проблемы.
